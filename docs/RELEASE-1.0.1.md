# StudioLive Control 1.0.1

Branding update for Windows and macOS, October 22, 2026.

- Consistent StudioLive Control naming in the inspector, package metadata, license attribution and mixer client description.
- Installer downloads use `StudioLive-Control.streamDeckPlugin`.
- Published plugin/action UUIDs and the settings location remain compatible with existing profiles and mixer addresses.

Install with Stream Deck running. Existing keys keep their assignments. See the [user guide](USER-GUIDE.md) for setup and the [test report](../TEST-REPORT.md) for verification scope.
