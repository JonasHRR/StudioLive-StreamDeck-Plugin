Custom color replaces the normal mixer color on this button. MUTE stays red; unknown/offline stays gray. FADE -- lightens the current button color with white. Mixer colors are never changed.
For Multi-Actions, choose “Mute on” or “Mute off”. Mute groups use the existing mixer assignments.
Each press switches between −∞ and 0 dB. At the floor, the next press fades in; otherwise it fades out. Press again during a fade to reverse it. The button shows the next press: FADE OUT or FADE IN. Both directions use the duration below; selecting this action starts with 3 s if the duration was 0. 0 = instant · up to 60 s = smooth fade. Target −60 to +10 dB; −84 = fader floor. dB values are approximate. The first positive step from the floor starts at ≈ −60 dB. Toggle fade alone uses FADE OUT / FADE IN for the next press. Fixed targets (including −∞ and 0 dB) use FADE UP / DOWN from the current level; relative steps use UP / DOWN by sign.
A fade that would leave the confirmed level unchanged shows FADE -- with a lighter tint of its button color and gray text. Moving away from the goal restores the direction and normal color. Toggle fade keeps its next-press preview. Another level command or a detected external fader move stops the fade. Stopping a fade sends no level value. Mute is independent.
The address is saved on this computer for all buttons and restored after restart. One TCP connection, port 53000. Changing the address discards pending commands.
