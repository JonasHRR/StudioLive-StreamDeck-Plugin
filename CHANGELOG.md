# Changelog

## 1.0.1 — 2026-10-22

- Use StudioLive Control consistently for package metadata, installer downloads, license attribution and the mixer client description.
- Retain the published plugin/action UUIDs and settings location so existing profiles and saved addresses remain compatible.

## 1.0.0 — 2026-10-22

Initial release for Windows and macOS.

- Direct Stream Deck control of PreSonus StudioLive Series III mixers.
- Input, bus and FX-return mutes, existing mute groups, and input-to-Aux/FX send mutes.
- Fixed and relative levels, smooth fades, fade stop, and toggle fades between −∞ and 0 dB.
- Inputs 1–64 where mixer feedback is available, plus A1, A2, Tape and Talkback.
- Live mixer names and colors, custom button names and colors, and synchronized duplicate buttons.
- Shared mixer settings saved locally on Windows and macOS.
- Confirmed state feedback, bounded command handling and automatic reconnect.

Requires Windows 10/11 or macOS 13+, and Stream Deck 7.1 or later.
